# Модуль: Станции метро и нечёткий поиск

## Таблица MetroStations (БД)
- **id** (PK): автоинкремент.
- **name** (String 200): название станции (напр. «Арбатская»).
- **line** (String 200): название линии (напр. «Арбатско-Покровская»).

Таблица заполняется автоматически при первом запуске через `bot/seed.py`.  
Поддерживается **266 станций** всех линий Московского метрополитена, включая:
- Сокольническая, Замоскворецкая, Арбатско-Покровская, Филёвская, Кольцевая
- Калужско-Рижская, Таганско-Краснопресненская, Калининская
- Серпуховско-Тимирязевская, Люблинско-Дмитровская, Большая кольцевая
- Бутовская, Солнцевская, Некрасовская, Троицкая (частично)

## Алгоритм нечёткого поиска (`bot/metro_search.py`)

### `best_metro_match(query, stations, threshold=0.45)`
Находит станцию с наибольшим коэффициентом сходства:
1. Приводит запрос к нижнему регистру.
2. Для каждой станции:
   - Если запрос — подстрока имени станции → score = 0.85 + 0.15 × (len(query)/len(name)).
   - Иначе → `difflib.SequenceMatcher.ratio()`.
3. Возвращает станцию с лучшим score, если он ≥ threshold.

### `top_metro_matches(query, stations, limit=5, threshold=0.35)`
Возвращает до `limit` станций, отсортированных по score убыванию.

### Сценарий выбора метро в боте
1. Пользователь выбирает «🚇 Ввести станцию метро» или «📍 Отправить геопозицию».
2. **Геопозиция**: Принимается (мобильный TG). На Desktop геопозиция недоступна — бот сообщает об этом и предлагает ввести название текстом.
3. **Текстовый ввод**: 
   - Ввод валидируется через `MetroTextInput` (Pydantic): min 2 символа.
   - Если 1 совпадение или top-1 score > 0.85 → показывает одну станцию с подтверждением.
   - Если несколько совпадений → Inline-кнопки с top-5 вариантами.
   - Если ничего не найдено → просит повторить.
4. Пользователь подтверждает или ищет заново.
