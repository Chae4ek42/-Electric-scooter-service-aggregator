# Модуль Metro Search

## Назначение

Модуль обеспечивает устойчивый ввод станции метро: пользователь может ввести неполное или неточное название, а бот предлагает наиболее вероятные варианты.

Важно: после внедрения city-first этот модуль применяется только для сценариев Москвы.
Для других городов вместо метро используется адрес + геокодирование.

## Источник данных

- Таблица `metro_stations` в БД.
- Заполняется при `init_db()`.

## Ключевые функции

- `best_metro_match(query, stations, threshold=...)`
    - Возвращает лучший матч или `None`.
- `top_metro_matches(query, stations, limit=5, threshold=...)`
    - Возвращает список кандидатов с оценкой похожести.

## Поведение в интерфейсе

1. Пользователь вводит станцию.
2. При уверенном единственном матче бот просит подтверждение.
3. При нескольких матчах показывает shortlist кнопками.
4. При отсутствии совпадений просит уточнить запрос.

## Принципы

- Нет внешних API, значит минимальная стоимость и предсказуемая задержка.
- Модуль независим от FSM, его легко переиспользовать в других потоках.
