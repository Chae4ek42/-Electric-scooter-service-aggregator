# Модуль Ranking

## Цель

Из множества сервисов выбрать наиболее подходящий под конкретную заявку клиента.

## Вход

`RankingContext`:

- тип услуги,
- категория (если применимо),
- метро пользователя,
- дата и время записи.

## Этапы ранжирования

1. Фильтрация по доступности и завершённости профиля (`is_available=True`, `registration_complete=True`).
2. Фильтрация по типу сервиса:
    - `repair` -> `repair|complex`
    - `upgrade` -> `upgrade|complex`
    - гидроизоляция -> `has_hydroisolation=True`
3. Фильтрация по предмету заявки:
    - для `repair` учитывается категория ремонта (`Service.category_rel`),
    - для `upgrade` учитываются `upgrade_categories`,
    - для `complex` должны выполняться оба условия.
4. Проверка рабочего дня и часов работы (`working_days`, `open_time/close_time`) относительно выбранного `scheduled_date/scheduled_time`.
5. Подсчёт скора.

## Формула

`score = 0.6 * proximity + 0.4 * rating`

## Proximity

- Базовая стратегия: метро-граф с учетом пересадок.
- Используется шкала дистанций по графу пересадок:
    - `dist=0 -> 1.00`
    - `dist=1 -> 0.85`
    - `dist=2 -> 0.65`
    - `dist=3 -> 0.45`
    - `dist>=4` или отсутствует путь -> `0.25`
- Если данные о метро отсутствуют, используется нейтральный score.

## Rating

- Если `yandex_rating` заполнен: `rating_score = min(rating, 5.0) / 5.0`.
- Если рейтинг отсутствует: используется нейтральный `rating_score = 0.5`.

При равном итоговом score сервисы дополнительно сортируются по `yandex_rating`.

## Fallback по времени

Если сервисов в выбранный слот нет:

- возвращается флаг `time_fallback=True`,
- выбирается top-сервис по общему скору,
- по его рабочим дням/часам рассчитываются ближайшие допустимые слоты `suggested_slots` (несколько вариантов дата+время),
- в результате возвращаются `fallback_service_id` и `fallback_service_name`,
- для обратной совместимости дублируется первый вариант в `suggested_date + suggested_time`.

## Расширяемость

Архитектура построена через `ProximityStrategy` protocol: можно подключить GPS-геокодинг без изменения хендлеров.
