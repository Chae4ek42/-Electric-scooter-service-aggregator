# Структура Google Таблицы

## Подключение

| Переменная | Описание |
|---|---|
| `GOOGLE_SHEET_ID` | ID таблицы из URL (`https://docs.google.com/spreadsheets/d/{ID}/`) |
| `GOOGLE_SA_PATH` | Путь к JSON-ключу Service Account (`service-account-key.json`) |

**Приоритет доступа:**
1. Service Account (приватная таблица) — если `GOOGLE_SA_PATH` задан
2. Публичный CSV-экспорт (fallback) — если SA недоступен

Service Account должен иметь права **Editor** на таблицу.

## Лист «Сервисы»

### Обязательные столбцы

| Столбец | Тип | Пример | Описание |
|---|---|---|---|
| **Название** | строка | `Motrax Mall` | Уникальное имя сервис-центра (ключ upsert) |
| **Специализация** | строка | `ремонт` / `апгрейд` / `комплекс` | Тип услуг. Регистр не важен |

### Рекомендуемые столбцы

| Столбец | Тип | Значения / Пример | Описание |
|---|---|---|---|
| Рейтинг Я.Карты | число | `4.8` | Рейтинг на Яндекс.Картах (0–5.0) |
| Телефон | строка | `+7 999 888-77-66` | Контактный телефон |
| Telegram | строка | `@fix_phone_shop` | Телеграм-хэндл |
| Адрес | строка | `ул. Ленина, 15` | Физический адрес |
| Метро ближ. | строка | `Курская` | Ближайшая станция метро (используется для ранжирования) |
| Статус | строка | `Заключён договор` | Статус партнёрства (информационное поле) |
| Доступен | строка | `Да` / `Нет` | Доступен ли сервис для заявок (`is_available`) |
| Категория | строка | `Механика` / `Электрика` / `-` | Категория неисправностей (для ремонта) |
| Открытие | `HH:MM` | `09:00` | Время открытия |
| Закрытие | `HH:MM` | `21:00` | Время закрытия |
| Гидроизоляция | строка | `Да` / `Нет` | Предоставляет ли услугу гидроизоляции |
| Диагностика | число | `500` | Стоимость диагностики (руб.) |
| Входит в стоимость | строка | `Да` / `Нет` | Входит ли диагностика в стоимость ремонта |
| Категории апгрейда | строка | `Окраска,Прошивка` | Через запятую (записываются при одобрении партнёра) |
| Рабочие дни | строка | `Пн,Вт,Ср,Чт,Пт` | Через запятую |

### Итого: 17 столбцов

```
Название | Рейтинг Я.Карты | Телефон | Telegram | Адрес | Метро ближ. | 
Специализация | Статус | Доступен | Категория | Открытие | Закрытие | 
Гидроизоляция | Диагностика | Входит в стоимость | Категории апгрейда | Рабочие дни
```

## Правила парсинга

1. **Регистронезависимый поиск** — названия столбцов ищутся без учёта регистра.
2. **Неизвестные столбцы** — игнорируются.
3. **Дубликаты заголовков** — при чтении через SA второй одноимённый столбец получает суффикс `_dup` и игнорируется.
4. **Пустое «Название»** — строка пропускается.
5. **Неизвестная «Специализация»** — логируется предупреждение, для новых записей используется тип `complex`.
6. **Булевы значения** — принимаются: `Да`, `Yes`, `1`, `True` (регистронезависимо).

---

## Логика синхронизации (upsert)

1. При запуске бота вызывается `run_full_sync()` → `sync_services_from_sheet()`.
2. Для каждой строки ищется `Service` по `name` (exact match).
3. **Новый** — создаётся запись.  
4. **Существующий** — сравниваются поля: если хотя бы одно изменилось, запись обновляется.
5. Лог: `Sheets sync: добавлено N, изменено M, без изменений K`.
6. **Ошибка**: если таблица содержит строки, но ни одна не обработана (все имена пусты / столбцы не найдены) → `ValueError`, бот не стартует.

## Write-back (при одобрении партнёра)

Файл: `bot/services/sheets_writer.py`

При одобрении партнёра через админ-панель запись добавляется в конец листа «Сервисы» функцией `add_service_row(svc)`.

Порядок столбцов при записи совпадает с таблицей выше (17 колонок).

Типы транслируются:
- `repair` → `Ремонт`, `upgrade` → `Апгрейд`, `complex` → `Комплекс`
- `True` → `Да`, `False` → `Нет`

---

## Фоновая синхронизация

Оба бота (клиентский и партнёрский) запускают фоновый цикл `_sheets_sync_loop` с интервалом `SHEETS_SYNC_INTERVAL` секунд (по умолчанию 300 сек = 5 мин).

Ошибки фоновой синхронизации логируются, но не прерывают работу бота.
