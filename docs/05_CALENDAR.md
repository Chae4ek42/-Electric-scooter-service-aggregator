# Календарь и Слоты

## Таймзона
Все календарные вычисления ведутся в московском времени.

Реализация устойчива к средам без tzdata:
- сначала `Europe/Moscow`,
- при недоступности — fallback на фиксированный `UTC+3`.

## `calendar_kb()`
- Показывает ближайшие `CALENDAR_DAYS` дней.
- Сегодня включается только если есть хотя бы один будущий слот.
- Формирует callback `date:DD.MM.YYYY`.

## `time_slots_kb(date_str)`
- Для сегодняшней даты исключает прошедшие часы.
- Для будущих дат использует полный диапазон `WORK_HOUR_START..WORK_HOUR_END`.
- Шаг слота задается `TIME_SLOT_MINUTES`.

## UX-правило
На экранах выбора даты/времени всегда доступна кнопка возврата, чтобы пользователь не терял контекст заявки.
