# Модуль: Календарь и выбор времени

## Логика календаря (`bot/keyboards.py`)

### `calendar_kb(booked_dates=None)`
Генерирует Inline-клавиатуру с датами на ближайшие **14 дней** (параметр `CALENDAR_DAYS`).
- Начинается с **завтрашнего дня** (today + 1).
- Формат кнопки: `DD.MM (день недели)`, напр. «07.04 (Mon)».
- Callback data: `date:DD.MM.YYYY`.
- Кнопки расположены по 3 в ряд.
- Последний ряд — кнопка «⬅️ Назад».

### `time_slots_kb(date_str)`
Генерирует почасовые тайм-слоты между `WORK_HOUR_START` (10:00) и `WORK_HOUR_END` (20:00).
- Шаг: `TIME_SLOT_MINUTES` (60 мин).
- Формат: `HH:MM`, callback: `time:HH:MM`.
- Кнопки по 4 в ряд.
- Последний ряд — кнопка «⬅️ Назад».

### Конфигурация (`bot/config.py`)
| Параметр | Значение | Описание |
|---|---|---|
| `CALENDAR_DAYS` | 14 | Количество дней для выбора |
| `WORK_HOUR_START` | 10 | Начало рабочего дня |
| `WORK_HOUR_END` | 20 | Конец рабочего дня |
| `TIME_SLOT_MINUTES` | 60 | Интервал между слотами |

### Flow
1. Пользователь выбирает дату из календаря.
2. Бот показывает доступные временные слоты этого дня.
3. После выбора времени — переход к подтверждению заявки.
4. Кнопка «Назад» из времени → вернуть к календарю.
5. Кнопка «Назад» из подтверждения → вернуть к выбору времени.
